\section{Next Steps}
\label{sec:nextsteps}

Moving forward, we plan to extend this work in the following directions:
\begin{enumerate}
    \item \textbf{Temporal-Aware Dense Retrieval:} Fine-tuning the dense encoder (e.g., using contrastive learning with temporally hard negatives) to embed temporal relationships directly into the semantic space.
    \item \textbf{Query Decomposition:} Integrating the intermediate steps provided in Sub-track 1b to perform multi-hop retrieval, addressing the complex reasoning failures identified in our error analysis.
    \item \textbf{Advanced Hybrid Fusion:} Exploring learning-to-rank models (e.g., LambdaMART) that take both BM25 and Dense scores as features, rather than relying on unsupervised RRF.
\end{enumerate}
